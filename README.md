# TCPipe

**TCPipe** is a real estate transaction management platform designed for transaction coordinators and real estate brokers. It helps users organize, monitor, and manage real estate deals throughout the entire transaction process.

The platform provides a centralized workspace for tracking active transactions, monitoring important deadlines, identifying high-risk deals, and managing transaction details.

## Features

### 1. Dashboard (`index.html`)

The Dashboard provides an overview of all real estate transactions, allowing users to quickly assess the status of their deals and identify items that require attention.

The dashboard includes:

- **Items Closing in 7 Days** – Displays transactions scheduled to close within the next seven days.
- **Overdue Deadlines** – Highlights transactions with deadlines that have passed.
- **High Risk Deals** – Identifies transactions flagged as high risk.
- **Past-Due Closings** – Displays transactions with closing dates that have already passed.
- **Active Deals** – Shows the total number of currently active transactions.

### 2. New Deal (`add.html`)

The New Deal page allows users to create and add new real estate transactions by entering relevant information into designated fields.

Transaction information is organized into the following sections:

- **Basic Info** – General transaction and file information.
- **Parties** – Information about the individuals involved in the transaction.
- **Dates & Deadlines** – Important dates, milestones, and transaction deadlines.
- **Location** – Property address and location details.
- **Financials** – Financial information related to the transaction.
- **Title & Lender** – Title company and lender information.
- **Risk & Notes** – Risk assessment and additional transaction notes.
- **Milestones** – Important stages and progress throughout the transaction.

### 3. Transactions

The Transactions page displays all deals entered through the New Deal page in one centralized list.

Each transaction includes the following information:

| Field | Description |
|---|---|
| File ID | Unique transaction identifier |
| Address | Property address |
| Stage | Current stage of the transaction |
| Closing Date | Scheduled closing date |
| Days to Close | Number of days remaining until closing |
| Risk | Current transaction risk level |
| Actions | Available transaction management actions |

#### Filtering and Management

Users can organize and manage transactions using the following features:

- **Filter by Stage** – Filter transactions based on their current stage.
- **Filter by Risk Level** – Narrow down transactions according to their assigned risk level.
- **Edit** – Update existing transaction information.
- **Delete** – Remove transactions.
- **Compose Email** – Compose an email related to a specific transaction.

## Purpose

TCPipe aims to simplify real estate transaction management by bringing deal information, deadlines, risk indicators, and transaction actions into one accessible platform.

It helps transaction coordinators and brokers stay organized, track progress, and keep important details within reach throughout the real estate closing process.
